# Setting this up as your GitHub profile

GitHub shows a README at the top of your profile page only if it comes from
a very specific repo: one named **exactly** your username.

## Steps

1. Go to github.com, click New repository.
2. Name it exactly `joshisnthere` (must match your username exactly, case
   included). GitHub will show a banner confirming this is your special
   profile repo.
3. Make it Public, initialize with a README if it asks (you'll overwrite it).
4. Upload these two things into that repo, keeping the same folder
   structure:
   - `README.md`
   - `assets/banner.png`
5. Commit. Your profile page (github.com/joshisnthere) will now show this
   README above your pinned repos and contribution graph.

## Editing it later

- Open `README.md` on GitHub and click the pencil icon to edit directly in
  the browser, or clone the repo and edit locally.
- The "about" section and tagline are placeholder text on purpose --
  replace those two spots with your own wording.
- To change which languages show up in the skills row, edit the `i=`
  list in the skillicons.dev image URL (comma separated, no spaces).
  Full list of supported names: https://skillicons.dev
